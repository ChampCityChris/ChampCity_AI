# ChampCity A/I Product Line — Desktop and Server

**Status:** Superseded V2 product/deployment decision  
**Superseded by:** [ChampCity A/I Product Deployment Model — Web Client and Service Host](PRODUCT_DEPLOYMENT_WEB_CLIENT_AND_SERVICE_HOST.md)  
**Superseding architecture:** [V2 Web Client and Service Host Architecture](../architecture/CHAMPCITY_WEB_CLIENT_AND_SERVICE_HOST_ARCHITECTURE.md)

This file is retained because historical V1/V2 reconciliation documents reference the former Desktop/Server product-line decision.

The former decision that **ChampCity A/I Desktop remains a permanent first-class V2 product** is no longer current.

The adopted V2 direction is now:

- one browser-delivered ChampCity Web Client;
- one ChampCity Service Host/backend architecture;
- Service Host deployable locally on a workstation or on a server;
- the same web client for either deployment;
- Electron/Desktop retained only as the V1 implementation baseline and migration source;
- no permanent V2 Electron/Desktop client.

Do not use the former Desktop/Server split as an implementation target.
