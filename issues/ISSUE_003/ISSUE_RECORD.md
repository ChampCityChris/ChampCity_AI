# ISSUE_003 — Issue Intake - Screenshot Functionality

## Issue
The Issue Intake screen should have a space to paste screenshots to include in the artifact record.

## Current Consequence
Without a screenshot function visible issues have to be described in words when a simple screenshot could be more valuable and provide an easier input path

## Needed Capability
Add the ability to upload screenshots into the artifact record for the AI to use for diagnosis of Issue.  This should be done in a way that can take a screenshot straight from the clipboard and paste it into the intake form, identical to how screenshots can be pasted in line into the chatgpt.com chat bubble.

## Discovery Context
Discovered when trying to enter an issue for a defect in the Development workflow's implementer workspace.

## Status
Issue recorded. Architect Planning pending.
