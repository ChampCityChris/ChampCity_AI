# ISSUE_002 — Open Application Landing Page

## Issue
Currently the application opens to the most recent project opened. This is confusing to the user on how to create a new project or navigate to an existing project not currently opened as the capability to do so lives in the left hand pane.

## Current Consequence
Bad UX design leads to User confusion

## Needed Capability
A landing page.  When the application is first opened it should be one workspace.  No left side pane.  This landing page can have a large ChampCity A/I logo with smaller card button below that start a new project or open existing project.

## Status
Issue recorded. Architect Planning pending.
